# Daata Hamlet Residence: ground floor (REV-04)

Context for Claude Code. Read this first.

## What this is
This folder holds the ground-floor design of a 3-storey house on an irregular plot of 3,129.1 sq ft in Pakistan. Every drawing, PDF and 3D file is generated by Python from **one geometry file: `source/model.py`**. Never edit the PDFs or the DXF by hand: change `model.py`, then regenerate.

## Run the pipeline (from `source/`)
```
pip install shapely ezdxf matplotlib numpy mapbox-earcut bpy   # bpy = Blender as a Python module (large download)
set DH_STAIR=L            # or U   (PowerShell: $env:DH_STAIR="L")
python checks.py          # automated design checks; all must pass (currently 45/45)
python make_sets.py       # -> out/DH-GF-REV-04-<L|U>_Drawings.pdf and _Details.pdf
python export_dxf.py      # -> out/daata_hamlet_GF_v2.dxf (copy to DH-GF-REV-04-<L|U>.dxf)
python build_3d.py stills # -> stills/<L|U>_*.png  (Blender Cycles, ~2 min each)
python build_3d.py video 144 0 144   # -> frames/, then ffmpeg -> 360 mp4
python build_3d.py blend  # -> web/DH-GF-<L|U>.glb for a web viewer
```
Paths are now portable: `build_3d.py` resolves outputs relative to its own folder (`source/`), and the other scripts write to `out/`, `stills/`, etc. relative to the current directory. Run them from `source/`.

## Files
- `model.py`: survey pegs, levels, rooms, walls, columns, stair (both options), doors and windows, furniture, circulation routes.
- `checks.py`: verification checks covering boundary, Line B, setbacks, wall thickness ≤ 9", columns inside walls, door swings, ventilation, stair risers and headroom, ramp, door widths, hinge side and sliding doors.
- `draw_plan.py`, `draw_elev.py`, `draw_interiors.py`: drawings. `make_sets.py` builds the two A3 PDF sets. `export_dxf.py` writes the DXF. `build_3d.py` is the Blender model and renders.

## Units and conventions
- Decimal feet. Origin = survey peg P1. +X = east, +Y = north.
- Datum ±0 = road at P1, the highest point. The road falls 6' to P0.

## Fixed decisions (client-approved)
- Plot and lawn at ±0; nothing sits below the road. GF FFL +0'-6". 11'-0" floor to floor, 10'-6" clear.
- Walls: 9" maximum (4.5" partitions).
- Structure: 22 RCC columns of 9"×18", all on grid intersections. Grid X: B 36.5, C 51, C' 57, D 69, E 84.75. Grid Y: 1 = 3.375, 2 = 20.125, 3 = 28.5, 4 = 33.19, 5 = 44.06.
- Porch: ramp ~1:4.3 from the gate (−4'-3½") to a wheel-stop at −0'-9", then 2 risers of 7½", then a 3'-6" landing. Car max 15'.
- Main door D1: 6' double, centred on the porch at X 63, opening out. Sidelights W9 and W10.
- Drawing room guest door D9 (3'-6" pocket) opens off the porch landing.
- Guest lobby X 69.375–74.25, closed by door D8 on grid D. It leads to the drawing room (D10, pocket), the guest washroom (D11) and the store (D12, pocket).
- No powder room. No under-stair partition.
- Doors: rooms 3'-6", dressings 2'-6" sliding, baths 2'-0". Swing doors hinge on the corner side. Wardrobes have sliding shutters.
- Stair: 19 risers @ 6.95", 10" treads, landing +7'-6½".
  - Option L: flight-2 runs west.
  - Option U: compact U, flight-2 returns north.
  - The client has not yet chosen between L and U.
- Bed-2 suite is dress-through. OTS is 3'-0" clear. Lawn has a pedestrian gate with stone steps and stepping stones.
